# Changelog

## 0.1.0

First release: `AuctionHouse` for pusher-js and Laravel Echo (open listings,
recent sales, server-clock countdowns, price history per item type, catch-up
on every subscription) and the `@hibira-io/auction/server` authority
`createAuctionHouse()` (list, bid, buyout, cancel, last-seconds extension,
settlement with `reserve` / `release` / `settle` callbacks, `MemoryStore` and
a compare-and-set store interface for several servers).
